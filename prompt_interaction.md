Now Dargato won't be stopping at every intersection. He will be free for moving every direction he wants at any time.
The decisions and controls by the players are reflected instantly.

let's re-define the interactions and senses:

| Sense                | Phone interaction                                       | Fallback                                | Effect on the game                                                                                                                                                                                                                                                                                                                                                |
| -------------------- | ------------------------------------------------------- | --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sight                | Camera brightness                                       | Swipe up to prevent an eye from closing | Camera too dark = brighness level too low, Camera too bright = too much fog to see                                                                                                                                                                                                                                                                                |
| Movement - Speed     | Scratching the screen (top to bottom)                   | -                                       | Dargato walking faster or slower, no interaction = no movement. More interaction = moving the paws faster, but will move only if there is a path                                                                                                                                                                                                                  |
| Movement - Direction | Gyroscope                                               | Touch Joystick                          | Turning Dargato left or right in realtime                                                                                                                                                                                                                                                                                                                         |
| Memory               | Loudness level (blow or whisper on microphone)          | Tap on screen: faster = more sound      | No sound = the paticles making the path are so disperse that Dargato won't know where to walk and the buildings become more abstract and disperse and floaty, no sound = no movement even if the scratching is happening. More sound = the particles come together to build the paths and now Dargato can walk and the buildings come to their grounded positions |
| Instinct             | Shake the phone                                         | Scratching side to side                 | No movement = all the paths look the same dark gray color, more movement = the particles making the shortest path to home turn red                                                                                                                                                                                                                                |
| Heartbeat            | Tap on screen (pulse indicated on the main game screen) | -                                       | No tapping, the game will end, tap at beat = the game will continue, tapping too fast, the game will end. This will be a slider shown in the main game screen alongside the pulsing indicator.                                                                                                                                                                    |

If more than one player with the same sense, average all the values.
